# Model 2 - Experiment 1: Online Shopping Application Test Plan

## 📌 Experiment Overview
* **Aim / Objective:** Prepare a comprehensive test plan for an online shopping application covering product browsing, user authentication, wishlist management, order placement, payment processing, and order tracking.
* **IEEE 829 Compliant Quality Gates:** Includes in-scope modules, test environments, resource matrix, milestone schedules, entry criteria, suspension criteria, and exit criteria.
* **Main Java File to Write in Lab Exam:** [`ShoppingTestPlanApp.java`](file:///d:/PROJECTS/stalab/model2_01_shopping_test_plan/src/main/java/com/sta/testplan/ShoppingTestPlanApp.java)

---

## 🚀 How to Run on a New Computer

### 1. Prerequisites
* **Java 17 or 21 LTS** installed (`java -version`).
* **Apache Maven 3.8+** installed (`mvn -version`).

### 2. Run Commands
```bash
cd model2_01_shopping_test_plan

# Run Unit Tests
mvn clean test

# Run Main Interactive Quality Gate Validator
mvn compile exec:java
```
